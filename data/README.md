# Raw Data

This folder contains the original Excel dataset used as the source for the DQLab Fashion Sales Dashboard project.

The workbook includes five raw datasets:

- `Transaksi Penjualan`
- `Master Cabang`
- `Master Produk`
- `Kategori Produk`
- `Kalender Liburan 2017`

These datasets were imported into Power BI and transformed using Power Query before being used for data modeling, DAX calculations, and dashboard analysis.
